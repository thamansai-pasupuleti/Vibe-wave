# VibeWave

**Assignment:** Group 2 – Music Streaming Website

## About
A music discovery landing page with genres, curated playlists, trending artist cards and a join section. It is a visual concept and does not stream audio.

## Files
- `index.html` – webpage structure and content.
- `style.css` – colours, typography, layout and responsive styling.

## How to run
1. Extract the project folder.
2. Open `index.html` in a modern web browser.
3. Or open the folder in Visual Studio Code and use the Live Server extension.

## Technologies
- HTML5
- CSS3
- Responsive CSS media queries

## Customisation
Edit the HTML to change text, images, prices and contact details. Edit the CSS to change the design. External Unsplash images and Google Fonts require an internet connection.

## Note
This is a front-end student project. No backend, database, payment, booking or actual streaming service is connected.
